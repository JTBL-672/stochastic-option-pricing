# Stochastic & Numerical European Option Pricing Library

A modular, high-performance Python library for pricing European options using analytical solutions, numerical partial differential equation (PDE) solvers, and stochastic simulation techniques. 

Designed with clean software engineering practices and optimized using NumPy and SciPy, this repository demonstrates both quantitative finance rigor and clean code architecture.

---

## Project Architecture

The project is structured with a strict separation of concerns between core numerical pricing logic (`src/`) and the execution/benchmarking orchestration layer (`main.py`):

```text
stochastic-option-pricing/
│
├── src/
│   ├── __init__.py          # Package initialization marker
│   ├── analytical.py        # Closed-form Black-Scholes pricing engine
│   ├── pde_solver.py        # Implicit Finite Difference Method (FDM) PDE solver
│   └── monte_carlo.py       # Monte Carlo engine with antithetic variates
│
├── .gitignore               # Excludes temporary bytecode and cache files
├── main.py                  # Orchestration, validation, and benchmarking script
├── README.md                # Project documentation
└── requirements.txt         # Project dependencies
```

## Implemented Pricing Models

### 1. Analytical Black-Scholes Model (`src/analytical.py`)
Computes the exact closed-form price of European call and put options based on the continuous Black-Scholes-Merton formula:
$$C(S_0, t) = S_0 N(d_1) - K e^{-r(T-t)} N(d_2)$$

Where:
$$d_1 = \frac{\ln(S_0 / K) + (r + \frac{\sigma^2}{2})(T-t)}{\sigma \sqrt{T-t}}, \quad d_2 = d_1 - \sigma \sqrt{T-t}$$

### 2. Implicit Finite Difference Method (`src/pde_solver.py`)
Transforms the Black-Scholes PDE into a terminal value problem and solves it backward in time using an Implicit Finite Difference scheme. 
* Constructs a spatial stock price grid and a temporal time-step grid.
* Utilizes a tridiagonal matrix solver (Thomas algorithm via SciPy) at each time step, guaranteeing unconditional stability regardless of grid refinement.

### 3. Monte Carlo Simulation (`src/monte_carlo.py`)
Simulates risk-neutral geometric Brownian motion paths for the underlying asset:
$$S_T = S_0 \exp\left( \left(r - \frac{\sigma^2}{2}\right)T + \sigma \sqrt{T} Z \right)$$
* **Variance Reduction:** Incorporates Antithetic Variates ($Z$ and $-Z$) to drastically reduce standard error without increasing the total number of simulated paths.

## Getting Started

### Prerequisites
Ensure you have Python 3.8+ installed. Clone the repository and install the required dependencies:

```powershell
git clone https://github.com/JTBL-672/stochastic-option-pricing.git
cd stochastic-option-pricing
pip install -r requirements.txt
```

### Running the Benchmarks
Execute the main orchestration script to run all models against standard market parameters, printing a side-by-side comparison of option price, absolute error, and execution time:

```powershell
python main.py
```

## Key Takeaways & Engineering Highlights
* **Accuracy vs. Performance Trade-offs:** Highlights how analytical formulas yield instant exact solutions, whereas numerical methods balance computational complexity with precision.
* **Vectorized Computations:** Leverages NumPy vectorization to avoid slow Python loops during path generation and matrix operations.
* **Production-Ready Layout:** Implements clean package importing rules, version-controlled ignores (`.gitignore`), and a modular file tree suitable for extension.
